## 范围与方法

- 从原始映射清单筛出 `level=FUZZY` 且 `score<0.8` 的 **46条映射、42个旧文件**，其当前有效旧标记记录共 **1,290条**。分数是文件名匹配分数，不是内容正确率。
- 新版搜索范围为391更新文件的8个任务及此前64新增文件任务，共 **455个文件、11,997条知识**。当前快照时间：2026-09-23T19:18:09.011327+08:00；联合导出13,201个唯一ID，导出前后计数相等。
- 每个旧文件优先抽3条实质QA，按来源页码和ID排序取首/中/尾；不足3条全取，仅有segment的4个文件整段读取。`订单管理_管理您的跟踪信息`仅1条符合条件的QA。首轮116条，发现4条旧QA仅复述标题或空答，各补抽1条，合计120条记录、116条有效内容样本。
- 候选检索使用本地字符/词项检索及关键词扫描，再由本次会话逐条阅读判断，未另调LLM自动判定。先看原映射文件，再跨455个新版文件检索；不足时阅读segment和源DOCX，不能用低相似度直接认定缺失。
- 同ID自身命中、另一条旧标记候选均不计独立替代；此前F19S3未排除后一类，已纠正。仅文字比较，未逐张核验旧QA嵌图；页面入口、联系人、数值有变化会单列。segment覆盖表示已用segment证实，不代表已证明所有QA都遗漏。**抽样结果不等于整篇通过，也不等于允许删除。**

## 需要优先处理的映射

1. **FPU→FedEx不成立（F03）。** 三条分别涉及整车计费、路线/跟踪工单、装车固定与数量责任。完整内容在此前64新增批次的FPU记录自身已有，FedEx小包流程不能代替。54条带旧标记是391重跑前已存在的事实，不能据此称其内容过期，也不能与44条同ID upsert保留旧字段混为一谈。
2. **电话Warm→工单/邮件Cold不成立（F18/F19）。** Warm工单仅Wayfair可见且电话沟通，Cold回复直接发给客户；5分钟电话等待规则不能被邮件响应规则代替。电话FAQ和概述早已在新增批次，本次仅做保护边界评估。
3. **有更准确的跨文档承接。** CGF合同费率三条应找《CGF 头程物流服务：合同费率》；MCO添加在《多渠道项目常见问题解答》；补发配件类别与30天条件在同名《补发配件资格》；供应商项目概览不能用申请指南或绩效面板单独替换。
4. **归档失效不能当有效替代（F05/F38）。** 仓库成功秘诀明确2026-07-14已归档下架、内容不再有效；自定义添加指南明确2026-07-22已归档失效。F05部分内容可跨其他新版找到，F38三条不能仅凭相同文字判通过。
5. **真实版本变化。** 马来西亚第一升级联系人Mia→Zoe，第二升级分规划Tina/文件Maria Jovel；材料工具、批量编辑、物流追踪按钮与状态调整；Bazaarvoice时长由签约后最短30天改为指定同步伙伴后2–4周。应核实新版适用性，不将变化统称遗漏。

## 抽查发现的内容缺口与来源问题

- **新源文件已断尾：**《管理文件和使用媒体工具》未包含旧元数据错误后果且末尾`</sp`；《如何为现有产品链接添加新变体》属性步骤后残缺span；两份客诉数据面板有HTML断尾且缺旧At Risk行动计划；标题版产品展示工单指南末尾`<l`。这些样本不能只归因于知识生成遗漏。
- **多渠道赔偿金额（F28S4）：** 新segment和源DOCX均停在“订单履约费”，旧答为“履约费 + WSC”。已确认重复履约自提可赔，但金额未完整保留；不能把断尾解释为政策取消WSC。
- **其他未完整覆盖：** CFS无需托盘化、多箱重复违规仍需付转换成本、上架后5个工作日等待限定，以及部分品类内部目标。PowerReviews在新版池没有关键词命中，不能由只介绍另外两家伙伴推断其不合作。
- **QA质量问题另记：** 管理电子色卡和材料QA `4184323eb9c7c30c0b2e77d36fa578f2`混入抽取提示词，未作为替代依据；客诉阈值QA `fd5d4e8909f9c9134680ddc7299d18d7`出现“正常≥70%、警告30–70%、存在风险5%”的残缺/错位，应核原表。广告ROAS旧“可高达300%”与新“通常300%以上”方向不同。
- **不要误判为缺失：** OOSP末尾已有“满足要求联系账户经理报名”的QA；本次列为与旧“联系运营设上线日”的动作改写。订单操作、UCC自动标签、签章有效期等可通过segment补足候选QA表达。

## 后续审核与旧知识处理边界

本报告是内容替换可行性抽查，不是正式审核。后续应先修正明确不等价的映射、补齐源文件和缺失知识，并确认变化规则及归档内容的处理方式，再按原授权审核新版。新版未审核通过之前保留旧知识。
删除前必须以明确的旧ID集合逐条核定，保护新批次ID交集、已有新版自身、跨文件替代证据与共享内容ID；不能把旧标记、文件名相似或“样本全部覆盖”当删除依据。本次未产出可执行删除清单。
