# payoneer_olive 知识库清理与流水线修复（2026-09-06 ~ 09-11）

起因：线上跨平台答错与口径矛盾。三个 session 协作排查（本仓库负责知识侧，
payoneer-olive 负责检索验证，sellagents-forquality 负责日志侧）。

## 一、根因：群聊总结流水线两处后处理在改写答案

`scratchpad/summ_xlsx.py`（本次已修）：

```python
# 原 SYS 提示
1. **费用**：…不写具体金额；涉及费用写「具体费用请咨询招商经理」。
# 原 scrub()
if FEE.search(a) or MON.search(a):
    a = MON.sub('', FEE.sub('', a))                    # ← 直接删掉金额
    a = a.rstrip('。，,. ') + '。具体费用请咨询招商经理。'  # ← 补模板句
```

两类实测事故：

1. **语义残缺**：源对话「订单金额不满 25欧元…消费者支付 2.99欧元运费」
   → 输出「订单金额不满的订单，向消费者收取运费」（4 条）
   `MON` 正则分不清"我们的报价"和"平台公开规则里的数字"。
2. **答案反转**：源对话
   ```
   [07-23 11:16] 如果客户想要直接拉群的服务是需要购买会员还是？
   [07-23 12:01] 卖家可以免费 但是都得先提交portal啊
   ```
   → 输出「需购买相应会员套餐，具体费用请咨询招商经理」
   既丢了"先提交 portal"这一关键步骤，又把结论反转。

**修法**：SYS 改为"只写对话里真实说过的内容，源对话没说的一个字都不要补"；
`scrub()` 改为只标记 `hit`、不改写任何字符，费用红线交人工审核。

## 三、类目问题：Lowes 同名两 id

`load_category_map_dict` 建 `name_map_dict` 时按**类目名**做 key
（`search_index_data_interface.py:195`），**同名直接覆盖且无告警**。

payoneer_olive 类目树里有两个 Lowes（都 enabled、都是一级类目）：

```
2084859831857463298   name_map 胜出、检索实际使用    13 条
2092182846773497857   被覆盖、按名字查不到          95 条  ← Lowes 知识主体
```

后者含官方 PDF《Lowe's跨境平台简介-Andy》44 条 + 群聊沉淀 48 条（退货政策、
妥投率、客服响应要求），**对带类目过滤的检索永久不可见**。

已按用户指示把 95 条迁到 `2084859831857463298`（13 → 108 条），
segment 从 0 条变 8 条。**类目表里停用旧 id 需在管理后台操作，本仓库无权限。**

顺带：wayfair 也有重名类目（Account / Onboarding），但疑似二级类目、
父节点不同，`name_map_dict` 的 key 是全路径，风险较低。

## 四、检索侧发现（另两个 session 负责，此处仅备录）

1. `query_tag` 的 keyword/llm 打标会覆盖群名类目，导致整轮检索切到错误平台
   （596 条中 46 条打错，keyword 占 38）。
2. 线上 `category_ids` 恒带默认分组 `"1"`（400/400），其中 125 次只传 `['1']`。
   默认分组占掉召回名额中位数 78%（Lowes 类目仅 11 条知识时达 100%）。
3. 默认分组 604 条里**线上可召回仅 384 条**（其余 audit_result 不合格），
   其中 97% 经 LLM 复核确认为真跨平台通用（橄榄枝计划流程 + 派安盈账户占 65~76%），
   **不是"没分好类"，是业务本身就有这么多平台无关知识**。

## 五、测量口径：三个会导致错误结论的坑

1. **`/web_search` 的 `page_size > 10000` 静默返回 0 条**（ES max_result_window），
   HTTP 200 不报错。曾因此得出"0 条默认分组"的错误结论。
2. **按 `ext_info.from_file_name` 枚举会漏**：该字段为空的有 262 条，
   其中包含线上高频召回的条目。改用 `cate1_id` 或按类目枚举。
3. **数条数必须带 `audit_result in [1,2]`**：默认分组全量 604 vs 线上可召回 384，
   差 36%。不带过滤会高估影响面。
