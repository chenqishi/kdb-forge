# evaluate

Inputs: exact case, actual replies, raw clients, metadata and run-local caches. Outputs: per-side count/source membership/returned size and category violations, unresolved/ambiguous identities, web total comparison with text+filter oracle, optional small-category exhaustive ID-set check, old/new ranking intersection. Resolve source using actual returned _index/dataset/category rather than desired filter; indistinguishable copies remain ambiguous. For explicit _id restrictions, attach the independently fetched ES identity only to the source-membership predicate; never pretend _id is stored in _source. Expected empty categories are controls; nonzero membership plus empty ranked response is separately flagged without pretending it proves omission. Native reads exact four existing scopes, _mget<=40/source fields nonvector. SQL: none.
