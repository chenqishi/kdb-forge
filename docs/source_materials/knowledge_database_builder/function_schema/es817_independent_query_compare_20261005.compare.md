# compare

Pure comparison of two successful service result lists. Identity=(dataset,id). Record exact identity/order, overlap, positional agreement, top1/top5 agreement, missing IDs, score deltas, common content hashes q/a/content/ext_info/metadata/primary_category/synonyms_title, timestamp differences separately. Reject duplicate identity, null-ID error sentinel and invalid response. Metrics measure agreement, not relevance or mathematical ANN equivalence.

SQL: none.
