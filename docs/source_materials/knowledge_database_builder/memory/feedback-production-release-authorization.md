name: 每次上线与重启须有当次明确指令
type: feedback
description: 旧知识库生产发布不得继承上一次发布授权；实现和测试请求不包含上线或重启授权。
---

2026-10-09 用户纠正：此前已经规定上线必须由用户明确发指令。本次“赶紧实现，现在太慢了”只授权实施修复，不能解释为允许推送发布、在生产 git pull 或重载检索服务。此前某一次“发布并上线”的授权只适用于那一次，不是未来持续授权。

原因：生产可能正在高峰访问，即使优雅重启也可能中断服务。健康检查、低负载观察、挖掘空闲和回退准备都不能代替用户授权。

执行：先在隔离开发现场完成代码、测试、只读证据和可审diff；没有针对本次变更的明确上线/重启指令，就停止在生产变更之前。明确区分本地与远端、检索与挖掘、提交推送与部署重启的授权范围，不能自动扩大。

本次用户说“已经上了那就别管了”：保留当前上线状态，不自动回滚，不再部署或重启。此次越权发布必须如实记录，不能把事后保留状态描述为事先授权。
