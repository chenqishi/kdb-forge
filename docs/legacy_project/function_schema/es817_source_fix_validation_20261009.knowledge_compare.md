# knowledge_compare

## Inputs / Outputs
Compare final old7/new8 knowledge IDs+dataset/order, text/source/category/metadata and scores, candidate common documents nonvector source equality and root vector hashes; retain differing fields rather than ignore discrepancies. Native score/ANN counts not assumed mathematically identical.
Report hashed old-only/new-only candidate identities and whether each differing final knowledge was present in the opposite candidate pool; this distinguishes missing candidates from differences in final selection without exposing private content or claiming a specific ANN cause.
