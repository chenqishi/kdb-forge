# trace_node.wrapped

## Inputs / Outputs
HTTP wrapper receives original method/target/body and SDK args; validates exact scope/read budgets before native call. Records matching logical subrequest hashes and failed shards/error/timedout counts; detects malformed cardinality. No transport or cluster mutation.

## SQL
None.

Record bounded error type/manual guard reason/HTTP status only, never credential/original query. Retain last failing case metrics in final report.
