# Offline test execution and default pytest policy

Inputs: candidate-local tests, optional KDB_TEST_PYTHON and explicit baseline group. No KDB_LEGACY_ROOT/cross-repo import. Default smoke/offline tests only. Historical baseline_legacy/baseline_forge remain unchanged and are not default discovery.

install(root): idempotent process-lifetime sys.addaudithook before test import; deny socket.connect/bind/sendto/getaddrinfo, subprocess.Popen, os.system/exec/spawn/posix_spawn/fork and writes outside candidate/temp/explicit KDB_OFFLINE_OUTPUT_DIR. TestClient socketpair allowed; real TCP/UDP/DNS/listeners/process launches denied even if monkeypatch restores Python wrappers. Denial error contains operation name, no credentials or payload. Stdlib bootstrap before hook only, no business import. No SQL/ES clients are constructed by guard.
prepare_paths(root): candidate src/root/testing paths; when ignored private test SDK exists, explicitly select it for tests and verify elasticsearch8.17.x, print version and source; fail clearly on incompatible already-imported package. This is test-only SDK, never service runtime dependency selection.
audit(event,args): fail before underlying prohibited operation, maintain metadata counters; file reads allowed; write roots resolve symlinks. install does not pretend to block arbitrary hostile ctypes or kernel-level code, only accidental standard-library I/O in selected tests.
run main: disables pytest autoplugin loading before import, installs guard, resolves explicit curated smoke/retrieval/mining/audit groups, forwards pytest args. --group all is union of documented groups, not all history. Unknown group fails. --group history accepts explicit paths and still guard; no unguarded live mode. run_tests.sh safely delegates; original real runner byte-preserved as non-executable historical text.
Selected mining/audit/all groups explicitly deselect two preserved historical tests whose assertions require a real subprocess (Excel argv child and shell/flock child). Print exact deselected nodeids and reason; do not change those test assertions or relax the process guard. Explicit history selection keeps original behavior and is blocked if it attempts a subprocess. Report selected pass counts and deselection counts separately; original guarded failures remain evidence.
root conftest installs same guard for ordinary default pytest before tests collection. --noconftest is user opt-out for bare pytest; supported run_offline_tests.sh remains guarded independently of that flag.
Tests verify actual socket/process boundaries denied (no network sent/process started), no old-root path injection, selected SDK major/minor, and safe discovery config. Temporary files permitted for behavior tests, no real external writes.
