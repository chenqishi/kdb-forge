# main

Inputs: --execute optional, backup path. Default is check-only. No activation journal means already using legacy/not activated and no process action. Before execute validate backups, active configuration hashes, exact journal service identities and mining GET /health active_tasks/queue_size both zero. Refuse unfinished prior rollback; never launch duplicate processes. Execute only explicitly authorized 120 retrieval/mining rollback: SIGTERM exact parent processes, wait for descendants up to60s without SIGKILL; atomic restore configs, restart original recorded commands with untouched py38 interpreter and PATH/PYTHONPATH. Persist journal before stopping and after each new PID; health checks only GET /openapi.json and /health. No source-code rollback, git reset, ES/data/alias/mapping or other services. Config rollback cannot reverse post-cutover data writes. Failures remain visible and preserve phase/PID evidence for manual recovery.
