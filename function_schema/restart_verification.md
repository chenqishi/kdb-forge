# Static verification helper contracts
Normalize.visit_Name restores logical __file__; Normalize.visit_Call restores private literal values only, for AST comparison. bounded rejects >=4MiB reads; digest streams SHA256 in 1MiB blocks. Input is new assembly manifest and ignored candidate private defaults. Output is metadata-only mechanical_proof.json. No business import, SQL, ES, network or source mutation.
Cold-import helpers deny network/process creation and outside writes; routes are inspected without startup hooks. Offline pytest runner denies sockets before collection.

Review artifact helpers: redact(line) masks known private values/token shapes and sensitive literal assignments in review text only; sha(path) streams 1MiB blocks. Inputs are candidate files and ignored private defaults; outputs are redacted patches and metadata manifests, no private value output or business mutation.
